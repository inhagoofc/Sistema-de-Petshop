# Sistema de Atendimento Pet Shop

## Descrição do Projeto
Programa desenvolvido em linguagem C para controlo de atendimentos e faturação de serviços de um pet shop. Permite o registo de clientes, seleção de serviços e visualização de relatórios via terminal.
